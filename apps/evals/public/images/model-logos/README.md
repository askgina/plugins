- `openai.svg`: [OpenAI](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg)
- `claude.svg`: [Claude](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claude-color.svg)
- `meta.svg`: [Meta](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/meta-color.svg), used for Muse.

Retrieved September 16, 2026. SVG files are kept unmodified and served locally.

`grok.svg` is the [Grok AI mark from UXWing](https://uxwing.com/grok-ai-icon/),
retrieved September 18, 2026. It is governed by the [UXWing license](https://uxwing.com/license/),
not the MIT license for the LobeHub assets above. It represents Grok only.
The source SVG is unmodified. A CSS mask uses the surrounding text color so
the mark stays dark on light surfaces and light on dark surfaces.

`gemini.svg` is the [Google Gemini mark from UXWing](https://uxwing.com/google-gemini-icon/),
retrieved September 18, 2026, under the same UXWing license. Its original colors
and transparent background are preserved on both light and dark surfaces; no
inversion or monochrome filter is applied.
