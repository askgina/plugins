Predictions MCP at `https://askgina.ai/ai/predictions/mcp` publishes each tool below as a native MCP tool beside `bash`. Native tools add no authority, because `bash` can already call the host tools behind them. They let your client show and gate each action by its own annotation instead of treating one `bash` call as a single risk.

Annotations are the server's own declaration. A client can use them to decide when to ask you before a call. They are hints, not enforcement, so keep approving every money-moving action yourself. Run `tools/list` on your connection to see what your deployment advertises.

## Read, external provider

Reads live data from a market, blockchain or other provider. It changes nothing and can be repeated.

| Tool                           | Use it for                                                                             |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| `searchPredictionMarkets`      | Search Polymarket markets                                                              |
| `getExpiringMarkets`           | Markets that end soon                                                                  |
| `getPredictionSportsEvents`    | Sports events and their markets by league, team or date                                |
| `getPredictionSubjectMarkets`  | Markets about one subject, such as a person, company or asset                          |
| `resolvePredictionMarketExact` | One market and its outcome token ids from an exact slug, condition id, token id or URL |
| `getPredictionOrderbook`       | Order book of one market                                                               |
| `getSeriesMarket`              | The current or next market of a recurring series                                       |
| `getPolymarketPositions`       | Your open and redeemable positions                                                     |
| `getPolymarketOrderHistory`    | Your order history                                                                     |
| `getCrosschainPortfolio`       | Your balances across chains                                                            |
| `webSearch`                    | Search the web for context                                                             |
| `fetchUrl`                     | Fetch a web page for context                                                           |

## Read, Gina account

Reads only state Gina stores for your account. It calls no outside provider and can be repeated.

| Tool                               | Use it for                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| `getAccountAddresses`              | Your Gina wallet addresses                                                      |
| `listScheduledPrompts`             | Your scheduled prompts                                                          |
| `listPredictionEventSubscriptions` | Your prediction event subscriptions, their filters and status                   |
| `getPredictionEvents`              | Read order, trade and health events from your account's event log with a cursor |
| `listWebhookDestinations`          | Your registered webhook destinations, without URLs or secrets                   |

## Execute

Places, changes, cancels or settles an order, trade or fund movement. It acts at once, repeating it can repeat the effect, and it cannot always be undone.

| Tool                           | Use it for                                                                              |
| ------------------------------ | --------------------------------------------------------------------------------------- |
| `tradePredictionMarket`        | Execute an immediate Polymarket trade                                                   |
| `managePredictionOrders`       | List, create, replace and cancel orders                                                 |
| `redeemPredictionMarket`       | Redeem winning positions of resolved markets                                            |
| `splitMergePredictionPosition` | Split pUSD into YES and NO sets, or merge sets back into pUSD, on one Polymarket market |
| `topUpPredictionsBalance`      | Top up your Predictions balance from a source asset                                     |
| `withdrawPredictionsBalance`   | Withdraw ready Predictions balance to your own wallet                                   |

## Change an event subscription

Creates, changes, pauses or resumes a prediction event subscription. It changes only the subscription Gina stores for your account and moves no funds.

| Tool                                | Use it for                                                                  |
| ----------------------------------- | --------------------------------------------------------------------------- |
| `createPredictionEventSubscription` | Subscribe to order and trade events on your Polymarket account              |
| `updatePredictionEventSubscription` | Rename, refilter, pause, resume or change the destination of a subscription |

## Delete an event subscription

Deletes a prediction event subscription so it stops delivering. It moves no funds, and it is marked destructive because it cannot be undone.

| Tool                                | Use it for                                                 |
| ----------------------------------- | ---------------------------------------------------------- |
| `deletePredictionEventSubscription` | Delete a subscription; it sends one final terminated event |

## Register a webhook destination

Registers a webhook destination, or a Claude routine's fire URL, for prediction events and can return a generated signing secret once. A routine needs its own token instead of a generated secret. It changes only the destination Gina stores for your account and moves no funds. It is marked destructive so your client asks you first, and a secret it passes or returns appears in your client's transcript.

| Tool                       | Use it for                                                                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createWebhookDestination` | Register a webhook destination from a label, a URL and an optional `whsec_` secret, or a Claude routine fire URL with its token; a generated secret is returned once |

## Change a webhook destination

Replaces the signing secret of a webhook destination or disables it. It moves no funds and is marked destructive so your client asks you first. Disabling cannot be undone.

| Tool                             | Use it for                                                                                                                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rotateWebhookDestinationSecret` | Replace the signing secret of an active destination; a generated secret is returned once and the previous one keeps signing for 24 hours, except a Claude routine, which needs its new token |
| `disableWebhookDestination`      | Disable a destination for good and pause the subscriptions that use it                                                                                                                       |

## Test a webhook destination

Sends one test event to a webhook destination you registered and records the result. It starts a real automation on receivers such as Grok and a real Claude Code session for a routine, so it is not a read.

| Tool                   | Use it for                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `sendWebhookTestEvent` | Send one test event to a destination and return the HTTP status and an outcome; a Claude routine starts a real session |

## Delete a schedule

Deletes or archives a scheduled prompt so it stops running. It touches only Gina-held schedule state, and it is marked destructive because it ends a recurring automation.

| Tool                    | Use it for                           |
| ----------------------- | ------------------------------------ |
| `deleteScheduledPrompt` | Archive (disable) a scheduled prompt |

## Sandbox

Runs commands in a sandbox that can call every host tool the venue allows, including the execute class, so it carries the strictest class of the tools it can reach.

| Tool   | Use it for                                                          |
| ------ | ------------------------------------------------------------------- |
| `bash` | Scripts, files, SQL over fetched market data and composed workflows |

## Typed next steps

These tools return a typed `next` list beside their result. Each entry names a tool and arguments your client can offer as a button. Your client still shows the call and waits for your approval before it runs.

| Tool                           | Suggests                       | When                                                                                                                                                                                                                         |
| ------------------------------ | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getPolymarketPositions`       | `redeemPredictionMarket`       | You hold redeemable winning positions. With one, it fills that position's condition and token ids. With several, it redeems all of them.                                                                                     |
| `splitMergePredictionPosition` | `splitMergePredictionPosition` | A split preview needs confirmation. It suggests the same split with `authorized: true`, and you can edit the amount. If the market has already resolved, it suggests `redeemPredictionMarket` for that condition id instead. |

## Check that it works

1. Open your client's tool list for `https://askgina.ai/ai/predictions/mcp`.
2. Confirm `bash` and the tools above appear, and that every tool in the Execute class is marked destructive.
3. Ask “Show Polymarket markets that end today.” and check that the assistant calls `getExpiringMarkets`. Do not approve an Execute call you did not ask for.
