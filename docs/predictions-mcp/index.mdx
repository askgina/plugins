For Ask Gina's broader user-facing capabilities, including wallets, market research, Recipes, Memory, networks, fees, and safety boundaries, see the [Product Guide](/product-guide).

## Quick Success Check

<Steps>
  <Step title="Add the server">
    Add `https://askgina.ai/ai/predictions/mcp` to your MCP client and restart it.
  </Step>
  <Step title="Sign in">
    Your client triggers OAuth — sign in to Gina in the browser and approve access.
  </Step>
  <Step title="Verify">
    Ask your AI assistant to use the `bash` tool:

    ```json
    { "command": "echo ok" }
    ```

    You should see `ok` in the output.

  </Step>
</Steps>

## Safety

<Note>
  `bash` runs inside a sandboxed workspace. Start with read-only commands (search, list) before
  executing trades. Large trade orders require explicit confirmation.
</Note>
