## Searching Markets

Find prediction markets on any topic. Gina searches Polymarket's full catalogue.

### By Topic

```
"show me NBA markets"
"Trump election odds"
"Bitcoin prediction markets"
"Super Bowl winner odds"
"Fed rate decision markets"
"Oscar best picture predictions"
```

### By Date

```
"NBA games tomorrow"
"markets ending today"
"what's resolving this week"
"crypto markets expiring in the next 2 hours"
"sports predictions for this weekend"
```

### Trending & Popular

```
"what's trending on Polymarket?"
"show me the most popular markets right now"
"what are people betting on?"
"high volume prediction markets"
```

### Multi-Outcome Events

```
"who will win the Premier League?"
"World Cup 2026 odds"
"which team wins the NBA championship?"
```
