## 1. Add the Server

Follow [Spot client setup](/spot-mcp/client-setup) to add the server and authenticate. Use the configuration for your host.

## 2. Sign In and Approve

Restart the client, complete Gina OAuth in the browser, and approve Spot write access. `tools/list` should return `bash` plus the native tools in the [tool reference](/spot-mcp/features).

## 3. Verify

Call `getSimplePrice` directly with:

```json
{ "ids": "ethereum", "vs_currencies": "usd" }
```

To verify `bash` too:

```json
{ "command": "echo ok" }
```

```json
{ "command": "host-tools --brief" }
```

Native MCP clients publish each tool's input schema. Inside `bash`, inspect a write schema with:

```json
{ "command": "host-tools schema quoteSpotTransaction" }
```
