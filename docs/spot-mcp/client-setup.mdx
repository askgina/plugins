This is **write access (Degen mode)**. It requests `tools:execute` and can perform spot actions. For research only, use [Gina Read](/mcp-access/gina-read).

To get the Spot connection together with the LP skills, install the `ask-gina-spot` plugin instead. See [install for your host](/agents/plugins-and-skills#install-for-your-host).

## Claude Code

```sh
claude mcp add --transport http spot https://askgina.ai/ai/spot/mcp
```

Open `/mcp` in Claude Code and complete OAuth. See [Claude setup](/connect/claude) for the host's authentication flow.

## Codex

```sh
codex mcp add spot --url https://askgina.ai/ai/spot/mcp
codex mcp login spot
```

Alternatively, merge this into your Codex configuration, then run the login command:

```toml
[mcp_servers.spot]
url = "https://askgina.ai/ai/spot/mcp"
```

## Cursor

Merge the entry into `.cursor/mcp.json` or `~/.cursor/mcp.json`, preserving other servers:

```json
{
  "mcpServers": {
    "spot": {
      "url": "https://askgina.ai/ai/spot/mcp"
    }
  }
}
```

Connect and complete Gina OAuth from Cursor's MCP settings.

## Other clients and manual tokens

Use a [Streamable HTTP client](/connect/other-clients) with this venue URL. Check the host's support for execution tools before connecting. For Bearer-token clients, follow [authentication](/agents/authentication) and deliberately choose **Full access — view and execute**; keep only the required venue entry.

The credential must be valid for this venue and carry `tools:execute`. A read-only token or an old Gina execute grant is not a substitute. Complete a fresh connection if the grant is rejected.

Next: run the [read-only connection checks](/spot-mcp/quick-start) before attempting execution.

## Check that it works

Restart the client and complete Gina OAuth. In Claude Code, `/mcp` should list `spot` as connected. Run `tools/list`. It should return `bash` and the native Spot tools. Then call `getSimplePrice` with:

```json
{ "ids": "ethereum", "vs_currencies": "usd" }
```

Expected: the current ETH price in USD. This is a read-only call, so nothing executes. If the grant is rejected, read the last paragraph above and reconnect.
