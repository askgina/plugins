Spot MCP is Gina's dedicated write-capable server for token workflows. It exposes 23 native tools for Spot reads, LONG and Robinhood reads, account support, swaps, transfers, transaction execution, and scheduling. It also retains a sandboxed `bash` tool for scripts, files, SQL, short waits, and composed workflows.

## How It Works

Your client connects to:

```
https://askgina.ai/ai/spot/mcp
```

After OAuth sign-in and approval, call the native tools directly for ordinary work. Use `capabilities`, `host-tools`, and `ts-exec` inside the sandbox when a workflow needs composition.

## Access

Spot MCP is controlled by the global `mcp_spot_enabled` rollout flag. Authentication and `tools:execute` are still required when the flag is enabled.
