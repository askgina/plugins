Spot MCP connects your assistant to token research, swaps, transfers and liquidity provisioning. Manage and execute LP operations on **Uniswap on Robinhood Chain (EVM)** and **Raydium on Solana** through one MCP connection.

## Server URL

```
https://askgina.ai/ai/spot/mcp
```
