The native tool inventory below is checked against a pinned application registry. Run `tools/list` to verify your deployed connection. `bash` provides scripts, files, SQL, short waits and composed workflows; its host-tool allowlist includes these tools plus the sandbox-only analysis helpers `spot.captureDataset` and `spot.sql`.

For protocols, actions, restrictions and release evidence, use the [LP support matrix](/spot-mcp/liquidity-positions#capability-and-access). The inventory matches application revision `2e847ae3dd0523e7ea3e3b9944c9b6bcc232fd37`, reviewed September 28, 2026; a deployed connection can list tools added later. Chain coverage of the pool and Uniswap LP tools was rechecked against application revision `343f262cfa844710f1172d37f2008559914d9c25` on October 20, 2026.

## Pool reads

| Host tool            | Purpose                                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------- |
| `getPoolState`       | Pinned-block Uniswap V2, V3 or V4 pool state on Robinhood Chain, Base or Ethereum        |
| `getRecentPoolSwaps` | Recent swaps for a Uniswap V2/V3 pair or V4 pool ID on Robinhood Chain, Base or Ethereum |

Both take an optional `chainId`. Without it the pool is looked up on every chain, and a pool found on more than one chain is refused until `chainId` is given.

The [pool scanner skill](/spot-mcp/lp-skills#lp-pool-scan) reads public pool data outside Spot MCP and needs no connection.

## Writes

| Host tool                  | Purpose                                |
| -------------------------- | -------------------------------------- |
| `quoteSpotTransaction`     | Prepare a bound swap or transfer quote |
| `executeSpotTransaction`   | Execute the authorized current quote   |
| `getSpotTransactionStatus` | Reconcile transaction status           |

A quote or preparation request stops before execution. A complete imperative transaction request can authorize execution; material new terms need review. After submission, reconcile the exact operation. A submitted or pending result is not settlement, and a timeout never authorizes repeating a send. Report recorded amounts from attributable receipts; label quote values as estimates.

## Scheduling

| Host tool                    | Purpose                             |
| ---------------------------- | ----------------------------------- |
| `createScheduledPrompt`      | Create a schedule                   |
| `listScheduledPrompts`       | List schedules                      |
| `toggleScheduledPrompt`      | Pause or resume a schedule          |
| `deleteScheduledPrompt`      | Delete a schedule                   |
| `updateScheduledAgentConfig` | Update schedule agent configuration |

Spot schedules continue to run through Gina's fixed internal agent. `updateScheduledPromptCondition` is not part of Spot MCP. For recurring LP reviews that only flag and propose, see [scheduled LP monitoring](/spot-mcp/lp-scheduled-monitoring).

`webSearch` and `fetchUrl` are not part of Spot MCP. Use the MCP client's native web tools for outside context. Predictions and Perps host tools, `renderReadOnlyDashboard`, and every unlisted tool are denied.
