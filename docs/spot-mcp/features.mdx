description: "The complete host-tool boundary for Spot MCP"

Spot MCP exposes the following 29 tools directly. `bash` remains a separate tool for scripts, files, SQL, short waits, and composed workflows. Its host-tool allowlist covers the same 29 tools plus two sandbox-only analysis helpers: `spot.captureDataset` snapshots a caller-created SQL table, and `spot.sql` runs isolated queries over captured datasets.

## Liquidity positions (Uniswap v3/v4)

| Host tool              | Purpose                                                                  |
| ---------------------- | ------------------------------------------------------------------------ |
| `getLpPositions`       | List LP positions owned by the delegated wallet on Robinhood Chain       |
| `quoteLpOperation`     | Quote an open, increase, decrease, collect, close, or recenter operation |
| `executeLpOperation`   | Execute a previously quoted operation                                    |
| `getLpOperationStatus` | Read an operation's durable settlement status                            |
| `getLpAllowlist`       | List allowlisted pools and the current revision                          |
| `updateLpAllowlist`    | Grant or revoke a pool on the allowlist                                  |

LP reads and writes run against the user's delegated wallet on Robinhood
Chain (chain 4663). `getLpPositions` can also read another address, but that
result is labelled foreign and can never be quoted or executed.
`quoteLpOperation` returns a bound quote id plus explicit spend and receive
bounds; nothing is signed or sent until `executeLpOperation` submits that
quote. A status of submitted or pending means the outcome is still unknown;
settled, partial, or failed is reported only from chain evidence.

The per-user pool allowlist decides which pools may take new or increased
exposure. Revoking a pool never blocks exits: decrease, collect, and close
stay quotable on an existing position. `updateLpAllowlist` takes
`action: "add"` with the full pool identity, or `action: "remove"` with the
entry's `poolKey`, and requires the current `expectedRevision` from
`getLpAllowlist`. A v4 pool whose hook can return a liquidity delta cannot be
admitted.

## Writes

| Host tool                 | Purpose                                |
| ------------------------- | -------------------------------------- |
| `getSwapCalldatas`        | Prepare swap transaction data          |
| `getTransferCalldata`     | Prepare transfer transaction data      |
| `executeSupertransaction` | Execute an approved transaction bundle |

For an imperative transaction request, the agent prepares and executes without
requiring a phrase such as `confirm execute`. If preparation reveals a material
new term, it asks one normal question. After submission, it checks the returned
transaction hash against swap history and portfolio state for up to 20 seconds.
A landed receipt reports recorded amounts spent and received. A transaction that
has not appeared yet is reported as submitted/pending, with quote values clearly
labeled as estimates.

## Scheduling

| Host tool                    | Purpose                             |
| ---------------------------- | ----------------------------------- |
| `createScheduledPrompt`      | Create a schedule                   |
| `listScheduledPrompts`       | List schedules                      |
| `toggleScheduledPrompt`      | Pause or resume a schedule          |
| `deleteScheduledPrompt`      | Delete a schedule                   |
| `updateScheduledAgentConfig` | Update schedule agent configuration |

Spot schedules continue to run through Gina's fixed internal agent. `updateScheduledPromptCondition` is not part of Spot MCP.

`webSearch` and `fetchUrl` are not part of Spot MCP. Use the MCP client's native web tools for outside context. Predictions and Perps host tools, `renderReadOnlyDashboard`, and every unlisted tool are denied.
