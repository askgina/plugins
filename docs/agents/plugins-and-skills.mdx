Ask Gina publishes four plugins from one repository, [askgina/plugins](https://github.com/askgina/plugins), one for each MCP server. A plugin bundles an MCP connection and, for some plugins, agent skills. A **connection** makes tools available. A **skill** tells the agent when and how to use them. Authentication is still required.

| Plugin                 | MCP server                              | Access                                     | Install it to                                                                                                                               |
| ---------------------- | --------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `ask-gina`             | `https://askgina.ai/ai/gina/mcp`        | Read-only, `tools:read`                    | Research wallets, spot tokens, Hyperliquid and Polymarket. It cannot trade or move assets.                                                  |
| `ask-gina-spot`        | `https://askgina.ai/ai/spot/mcp`        | Write access (Degen mode), `tools:execute` | Quote and, with your approval, execute spot swaps, transfers and LP operations from Gina.                                                   |
| `ask-gina-perps`       | `https://askgina.ai/ai/perps/mcp`       | Write access (Degen mode), `tools:execute` | Read Hyperliquid and, with your approval, place and manage perpetual-futures orders and funding from Gina.                                  |
| `ask-gina-predictions` | `https://askgina.ai/ai/predictions/mcp` | Write access (Degen mode), `tools:execute` | Search Polymarket and, with your approval, trade prediction markets and manage your balance from Gina. It lists 25 native tools and `bash`. |

Install any of them. They are separate plugins, so installing the research plugin never adds trading tools. Only `ask-gina` and `ask-gina-spot` bundle skills. The Perps and Predictions plugins are the connection alone, and each lists its tools by annotation class on a native tools page: [Perps](/perps-mcp/tools) and [Predictions](/predictions-mcp/tools). The [skills catalog](/agents/skills-catalog) lists every skill, the plugin that ships it and whether the MCP server also serves it.

A skill that is not served over MCP is not available from a direct MCP connection alone. Install the plugin or copy the skill directory.

## Install for your host

All plugins live in one marketplace per host. Add the marketplace once, then install the ones you need. Spot, Perps and Predictions move real funds, so review every quote and order before you approve it, and read [Write access (Degen mode)](/write-access/index) first.

### Claude Code

```text
/plugin marketplace add askgina/plugins
/plugin install ask-gina@ask-gina-plugins
/plugin install ask-gina-spot@ask-gina-plugins
/plugin install ask-gina-perps@ask-gina-plugins
/plugin install ask-gina-predictions@ask-gina-plugins
```

Restart the session if prompted, then use `/mcp` to authenticate each included connection. Choose this route instead of adding a duplicate direct connection.

### Codex

```text
codex plugin marketplace add askgina/plugins
codex plugin add ask-gina@ask-gina-plugins
codex plugin add ask-gina-spot@ask-gina-plugins
codex plugin add ask-gina-perps@ask-gina-plugins
codex plugin add ask-gina-predictions@ask-gina-plugins
```

Start a new session and complete OAuth when Codex asks you to sign in. See [Codex setup](/connect/codex) for the direct connection route.

### Cursor and Grok Bot

Load a plugin folder as a local Cursor plugin: clone [askgina/plugins](https://github.com/askgina/plugins) and copy `plugins/<plugin-name>` to `~/.cursor/plugins/local/<plugin-name>`. Use a real directory, not an external symlink. Open the connector and choose **Connect** to complete OAuth. Grok Bot loads plugins only from the Cursor marketplace, and a live listing for these plugins has not been verified there. See [Grok Bot](/connect/grok-bot) and [other clients](/connect/other-clients) for the direct route.

### Devin

Add a `git-subdir` source to your Devin account or enterprise manifest. Use `plugins/ask-gina` for the research plugin and `plugins/ask-gina-spot`, `plugins/ask-gina-perps` or `plugins/ask-gina-predictions` for a write venue:

```json
{
  "requiredPlugins": [
    {
      "source": "git-subdir",
      "url": "https://github.com/askgina/plugins.git",
      "path": "plugins/ask-gina-spot"
    }
  ]
}
```

### GitHub Copilot

Copilot reads the manifest in each plugin's `targets/copilot` folder in the repository.

### Gemini

The Gemini extension includes only `ask-gina`. The write plugins are not available as Gemini extensions. To use a write venue from another client, connect the [Spot](/spot-mcp/client-setup), [Perps](/perps-mcp/client-setup) or [Predictions](/predictions-mcp/client-setup) MCP server directly.

### Hosts with manual skill loading

Install only the skill directories you want into the host's documented skill location, then start a new session. Take them from `plugins/<plugin>/skills/<skill-name>/` in the [source repository](https://github.com/askgina/plugins/tree/main/plugins). Use those sources rather than older skill bodies copied from documentation. Contributor instructions and build internals are not user skills.

[OpenClaw](/connect/openclaw) is one client, not a separate Gina skill family. Legacy ClawHub commands are not the installation source for Gina skills.

## Spot skills and LP work

The Spot plugin carries the LP skills. The scanner `lp-pool-scan` reads public data and needs no wallet or keys. The playbook `lp-rebalancing-playbook` reads live positions through [Spot MCP](/spot-mcp/liquidity-positions) and only proposes. Neither executes. [LP skills](/spot-mcp/lp-skills) explains how to run and read them, and the [LP agent workflow](/spot-mcp/lp-agent-workflow) shows how they combine with the Spot tools.

## Package availability

Source code and host adapters do not establish marketplace approval. Check [your client's setup guide](/connect/index#choose-your-client) for its direct connection route and marketplace availability. Do not assume SDK or CLI source can be installed from a public package registry.

## Check that it works

1. Start a new session and open the host's MCP or tools list. Confirm a connection appears for each installed plugin, such as `ask-gina`, `spot`, `perps` or `predictions`, and finish OAuth if it asks.
2. Ask the host to list its skills. Every skill the [catalog](/agents/skills-catalog) shows for your installed plugins should appear.
3. Ask **“Use Gina to show ETH in USD over the past seven days.”** A Gina tool should run. With `ask-gina-spot`, ask for a quote only, such as “Quote swapping 10 USDC for ETH,” and do not approve it. With `ask-gina-perps` or `ask-gina-predictions`, ask for a read such as “Show my Hyperliquid positions” or “Show Polymarket markets that end today,” and do not approve any order.
