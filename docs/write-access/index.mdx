Write access lets an agent perform supported actions on your behalf. In Gina's token setup, this is **Full access — view and execute**. It is separate from the read-only research plugin.

## Connect and verify

1. Choose a venue using the [access comparison](/mcp-access/index).
2. Follow that venue's setup page and authenticate with `tools:execute`.
3. Inspect available tools and current schemas. Spot provides native tools plus `bash`; Predictions and Perps provide `bash` with venue-specific host-tool allowlists.
4. Start with a read operation to check the account and market.
5. Follow the venue's execution workflow for the requested action, including result verification.

A direct request to send or swap can authorize execution. If you only want a proposal, say **“prepare”**, **“quote”**, or **“do not execute.”** Preparation and settlement are different states: a returned transaction hash can still be pending.
