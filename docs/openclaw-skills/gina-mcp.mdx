# Gina Read Skill

Gina Read is Safe mode: one read-only connection for Spot, Predictions, Perps, cross-chain holdings, linked addresses, and scheduled-prompt visibility.

## Server URL

```
https://askgina.ai/ai/gina/mcp
```

## Access Boundary

- OAuth scope: `tools:read`
- MCP surface: named read tools
- No `bash`
- No swaps, transfers, trades, funding, or scheduling mutations

The packaged plugin for ChatGPT, Codex, Claude, and compatible hosts is coming soon. Direct MCP connections can use the same server and scope.

<Info>
  For write access, connect [Spot MCP](/openclaw-skills/spot-mcp), [Predictions
  MCP](/openclaw-skills/predictions-mcp), or [Perps MCP](/openclaw-skills/perps-mcp) separately.
</Info>
