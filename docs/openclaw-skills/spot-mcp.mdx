# Spot MCP Skill

Use Spot MCP for token research, swaps, transfers, transaction execution, and scheduled prompts.

## Server URL

```
https://askgina.ai/ai/spot/mcp
```

## What You Get

- One MCP tool: `bash`
- A persistent `/workspace` sandbox
- Spot market reads and account-support tools
- Swap, transfer, and transaction execution tools
- Scheduled-prompt management
- Web search and URL fetching

## Quick Install

```bash
claude mcp add spot --transport http https://askgina.ai/ai/spot/mcp
```

Or use this generic MCP configuration:

```json
{
  "mcpServers": {
    "spot": {
      "transport": "http",
      "url": "https://askgina.ai/ai/spot/mcp"
    }
  }
}
```

## Smoke Test

Restart the client, complete Gina OAuth in the browser, and approve Spot write access. Then run:

```json
{ "command": "host-tools --brief" }
```

```json
{ "command": "host-tools getSimplePrice '{\"ids\":\"ethereum\",\"vs_currencies\":\"usd\"}'" }
```

See the canonical [Spot allowlist](/spot-mcp/features) before enabling agent-driven writes.

<Warning>
  Spot MCP uses `tools:execute`. Inspect schemas and confirm assets, chains, amounts, and
  destinations before financial actions.
</Warning>
