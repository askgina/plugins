## Choose a client

Select your agent above to open its setup guide, or find another client below.

Start with a direct read-only connection. Your host must support remote MCP and the authentication method shown below. Access can depend on your host's plan or workspace policy.

| Client                            | Setup route                                                    | Authentication                        | Skills and result UI                                        |
| --------------------------------- | -------------------------------------------------------------- | ------------------------------------- | ----------------------------------------------------------- |
| [ChatGPT](/connect/chatgpt)       | Custom connection in developer mode                            | OAuth                                 | Direct tools; rich results depend on host support           |
| [Claude](/connect/claude)         | Remote connector; Claude Code also supports repository plugins | OAuth                                 | Code plugin loads research skills; connector alone does not |
| [Codex](/connect/codex)           | Remote MCP configuration                                       | OAuth                                 | Skills can be installed separately                          |
| [Grok Bot](/connect/grok-bot)     | Plugins marketplace; Ask Gina listing unverified               | Browser authentication when requested | Plugin tools and packaged skills                            |
| [Perplexity](/connect/perplexity) | Custom remote connector                                        | OAuth                                 | Direct tools; Gina-specific rendering unverified            |
| [Hermes Agent](/connect/hermes)   | Remote MCP in `config.yaml`                                    | OAuth or manual token                 | Tools discovered on connection; Gina rendering unverified   |
| [OpenClaw](/connect/openclaw)     | Native MCP settings; optional skill directories                | OAuth or manual token                 | Skills load separately from MCP                             |
| [Others](/connect/other-clients)  | Cursor, Grok web, and other Streamable HTTP clients            | OAuth or Bearer token                 | Depends on the client                                       |

## Availability and verification

These setup routes are checked against the hosts' documentation. Authenticated Gina smoke tests in every host have not yet been completed. A client supporting MCP does not guarantee every Gina result widget is available.

Public Ask Gina marketplace listings for ChatGPT, Claude, and Cursor have not been verified here. Use the concrete direct-connection or source-install routes on these pages; do not interpret a repository manifest as marketplace approval.

All setup examples in this section use **read-only access**. If you need execution, first choose [Write access (Degen mode)](/write-access/index), then follow the venue-specific setup and your host's execution restrictions.
