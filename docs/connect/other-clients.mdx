Your client needs remote **Streamable HTTP** MCP support and either OAuth or a configurable Bearer header. Follow its own configuration schema; MCP settings are not identical across hosts.

## Configure a research connection

Use these connection values:

| Setting     | Value                            |
| ----------- | -------------------------------- |
| Name        | `ask-gina`                       |
| Transport   | Streamable HTTP                  |
| URL         | `https://askgina.ai/ai/gina/mcp` |
| OAuth scope | `tools:read`                     |

Prefer the client's OAuth flow. For a manual Bearer header, follow [authentication](/agents/authentication); use a correctly scoped token and private configuration. A client that only supports local stdio servers cannot connect directly with these values.

## Plugin or skill support

If the client supports skills, use [the canonical research skill directories](/agents/plugins-and-skills). If it only supports tools, you can still complete the first request without installing skills. Rich charts and slash commands depend on the host.

## Cursor: direct MCP

Merge this into your project `.cursor/mcp.json` or user `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "ask-gina": {
      "url": "https://askgina.ai/ai/gina/mcp"
    }
  }
}
```

Open Cursor's MCP settings and connect Ask Gina. Complete Gina OAuth in the browser, then enable its tools. This URL-only configuration lets Cursor negotiate Streamable HTTP and OAuth. See [Cursor MCP](https://prod.cursor.com/docs/mcp).

## Cursor: local source plugin

For skills and slash commands, clone [askgina/plugins](https://github.com/askgina/plugins) and copy the complete `plugins/ask-gina` directory to `~/.cursor/plugins/local/ask-gina`. Use a real directory, not an external symlink. Preserve any existing installation rather than overwriting it blindly.

Reload Cursor and connect the plugin's Gina MCP server. The plugin provides four research skills and the commands `/review-gina-account`, `/research-spot-tokens`, `/research-hyperliquid`, and `/research-prediction-markets`. Avoid enabling a duplicate direct MCP connection.

## Grok web

At [Grok connectors](https://grok.com/connectors), choose **New Connector → Custom**, enter `https://askgina.ai/ai/gina/mcp`, and complete authentication. Availability depends on the host. See [Grok's connector guide](https://docs.x.ai/grok/connectors).

## Verify your first result

Ask **“Use Gina to show ETH in USD over the past seven days.”** Confirm a Gina tool ran and the response identifies ETH and the requested period. Follow [First successful request](/start/first-request) for the expected tool boundary and recovery steps.

This connection is read-only. For trading or transfers, see [Write access (Degen mode)](/write-access/index). A direct connection does not automatically install [research skills](/agents/plugins-and-skills).
