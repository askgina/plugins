# Files and memory

Open **Files** in the sidebar to browse available account files. Memory stores notes for later chats or recipes. Sign in and confirm your account has access.

## Save and read a note

1. Ask **“Write ‘Watch ETH and SOL’ to research/watchlist.md in my account Memory.”**
2. Ask **“Read research/watchlist.md from my account Memory.”**
3. Check the contents. A missing path should return an error.

A write creates or replaces the whole file. To edit, read first and supply the full replacement. Keep a copy of anything you cannot lose.

Account Memory and an external MCP sandbox's `/workspace` are separate. Name the storage surface when ambiguous. A recipe with file access can read the named file; the public Docs Agent cannot access private files.

Never store passwords, tokens, private keys, or recovery phrases in notes.
