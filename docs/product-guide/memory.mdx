# Memory

## Purpose

Save notes for later chats or recipes. First, write `Watch ETH and SOL` to `research/watchlist.md`, then read it.

## Suitable Use Cases

Store research, a watchlist, or recipe output for later use.

## Prerequisites and Authentication

Sign in and confirm your account includes Memory. Only you can open its files. The public Docs Agent cannot read or change them.

## Inputs and Expected Results

Give an operation and path. Read returns the current contents. Write creates or replaces the whole file. List returns Memory paths. To edit, read the file and write the full replacement. MCP `/workspace` is separate from account Memory.

## Tested Example

> Read research/watchlist.md.

Expected: Gina returns the current contents. A missing path returns an error.

## Limitations and Safety

Do not store passwords, tokens, API keys, private keys, or recovery phrases. A recipe with file access can read the named file. Keep a copy of anything you cannot lose.
