# Leaderboard & Community

## Purpose

Season scoring shows which activity the current rules counted and where an account ranks. A score is not a payout or token entitlement.

## Suitable Use Cases

Check a season score or investigate a missing transaction hash.

## Prerequisites and Authentication

Sign in and select the season. The connected wallet must match the activity.

## Inputs and Expected Results

Provide the season and a transaction hash or public wallet. Ask Gina can return the recorded score and check a missing hash against the connected wallet, processing status, network, and current rules.

## Tested Example

> Why is this transaction hash not reflected in my score?

Expected: Ask Gina checks the wallet, season, transaction, network, processing status, and current rules. The check does not promise points or a completion time.

## Limitations and Safety

Seasons, formulas, rewards, and indexing can change. If this page differs, follow the [current rules](https://askgina.ai/leaderboard). Scores track activity. They do not create a cash balance, payout claim, or token entitlement. Genesis NFTs do not promise utility. Do not transact for points alone.
