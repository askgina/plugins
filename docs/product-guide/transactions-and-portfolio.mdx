# Transactions and portfolio

Open the wallet or ask **“Show my portfolio across chains.”** Check the account, chain, asset, and freshness. Missing provider data is not a zero balance.

## Prepare without submitting

1. Confirm the full recipient address, network, asset, and amount.
2. Ask **“Prepare to send 5 USDC on Base to [recipient address]. Do not execute.”** Replace the bracketed text with the verified address.
3. Check the proposal's recipient, network, contract, amount, and fees.
4. Give a separate execution instruction only when ready. Review material changes first.

## Execute and verify

A direct **send** or **swap** instruction authorizes same-turn execution; no special “confirm execute” phrase is required. For swaps, specify input asset, amount, output asset, and network. Quotes expire and fees can change.

Inspect **Trade History** or the chat result. Match the hash to your requested action. Submitted can mean pending; a hash alone does not guarantee finality. Check status before repeating an unclear send. Gina cannot recover a wrong send.
