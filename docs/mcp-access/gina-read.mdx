Gina Read is the read-only MCP connection for cross-market research and account visibility.

## Server URL

```
https://askgina.ai/ai/gina/mcp
```

It requests `tools:read` and lists named tools for Spot prices and charts, Hyperliquid state, prediction markets, cross-chain holdings, linked addresses, and scheduled-prompt visibility.

<Check>No `bash` tool</Check>
<Check>No swap, transfer, trade, funding, or scheduling mutations</Check>
<Check>One connection for reads across all three markets</Check>

## Connect and try it

Follow [your client setup](/connect/index), then run [First successful request](/start/first-request). For task examples, start with [account review](/read-only/account), [spot research](/read-only/spot), [prediction markets](/read-only/predictions), or [perps](/read-only/perps).

## When You Need to Write

Add only the venue-specific server you need:

- [Spot MCP](/spot-mcp) for swaps, transfers, transaction execution, and Spot scheduling
- [Predictions MCP](/predictions-mcp) for Polymarket execution
- [Perps MCP](/perps-mcp) for Hyperliquid and HIP-3 execution

Existing execute-scoped Gina credentials cannot be used on Gina Read. Reconnect through OAuth to receive a read-scoped token.
