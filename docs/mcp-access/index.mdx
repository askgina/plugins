Choose permissions before connecting a client. One read-only connection covers all markets; execution is split into three venue-specific connections.

| Access                    | Server URL                              | OAuth scope     | Purpose                                          |
| ------------------------- | --------------------------------------- | --------------- | ------------------------------------------------ |
| Read-only                 | `https://askgina.ai/ai/gina/mcp`        | `tools:read`    | Research and account visibility across markets   |
| Write access (Degen mode) | `https://askgina.ai/ai/spot/mcp`        | `tools:execute` | Spot execution, swaps, transfers, and scheduling |
| Write access (Degen mode) | `https://askgina.ai/ai/predictions/mcp` | `tools:execute` | Prediction-market execution                      |
| Write access (Degen mode) | `https://askgina.ai/ai/perps/mcp`       | `tools:execute` | Perpetual-futures execution                      |

## Read-only access

Choose [Gina Read](/mcp-access/gina-read) for prices, market discovery, positions, linked addresses, holdings, and schedule visibility. It exposes named research tools. It cannot trade, transfer, change leverage, or create schedules.

The [Ask Gina plugin and research skills](/agents/plugins-and-skills) use this connection. Installing the plugin does not grant execution access.

## Write access (Degen mode)

Choose [write access](/write-access/index) for an agent that should act on your behalf. Connect only the venue you need. Spot exposes native tools plus `bash`; Predictions and Perps expose `bash` with their own allowed host tools. See each venue's reference for the exact tool boundary.

Write access can place orders or move funds. A request to prepare or quote differs from a request to execute; follow the selected venue's workflow.

## Match the app's labels

In [Agent Setup](https://askgina.ai/agent-setup), **Read-only — view data** corresponds to Gina Read. **Full access — view and execute** corresponds to write access (Degen mode).

The token form can start with full access selected. For research, explicitly select **Read-only — view data** before generating a token. An existing execute-scoped credential is not a read credential: reconnect or generate a token with the correct scope.
