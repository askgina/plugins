Perps MCP at `https://askgina.ai/ai/perps/mcp` publishes each tool below as a native MCP tool beside `bash`. They use the same authenticated account, and your client can show and gate each action by its own annotations. Call native tools directly. Credential-bearing destination calls must not be wrapped in `bash`.

Annotations are the server's own declaration. A client can use them to decide when to ask you before a call. They are hints, not enforcement, so keep approving every money-moving action yourself. Run `tools/list` on your connection to see what your deployment advertises.

## Read, Gina account

Reads only state Gina stores for your account. It calls no outside provider and can be repeated.

| Tool                          | Use it for                                                                  |
| ----------------------------- | --------------------------------------------------------------------------- |
| `getAccountAddresses`         | Your Gina wallet addresses                                                  |
| `listPerpsEventSubscriptions` | Your Perps subscriptions, filters and lifecycle status                      |
| `listWebhookDestinations`     | Shared destinations and attachment counts, without receiver URLs or secrets |

## Execute

Places, changes, cancels or settles an order, trade or fund movement. It acts at once, repeating it can repeat the effect, and it cannot always be undone.

| Tool                              | Use it for                                     |
| --------------------------------- | ---------------------------------------------- |
| `placeHyperliquidOrder`           | Place a market or limit order                  |
| `placeHyperliquidStopOrder`       | Place a stop-loss or take-profit trigger order |
| `cancelHyperliquidOrder`          | Cancel an open order                           |
| `modifyHyperliquidOrder`          | Modify an open order                           |
| `adjustHyperliquidLeverage`       | Set the leverage of an asset                   |
| `updateHyperliquidIsolatedMargin` | Add or remove isolated margin on one position  |
| `depositToHyperliquid`            | Deposit USDC to Hyperliquid                    |
| `hyperliquidWithdraw`             | Withdraw USDC from Hyperliquid                 |
| `fundHIP3Dex`                     | Move USDC collateral into a HIP-3 DEX          |
| `returnHIP3DexFunds`              | Return USDC collateral from a HIP-3 DEX        |

## Start account observation

Creates a linked-account event subscription and requests collection after wallet and credential checks. It moves no funds and does not grant trading permission.

| Tool                           | Use it for                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `createPerpsEventSubscription` | Observe linked-wallet account changes with a labelled baseline, cursor replay and optional destination |

## Change account observation

Changes a Perps subscription's filters, destination or lifecycle after external wallet and credential checks. It can replace delivery configuration or close an invalid binding, but moves no funds.

| Tool                           | Use it for                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------ |
| `updatePerpsEventSubscription` | Rename, change future filters, retarget, pause or resume a native subscription |

## Account replay and lifecycle

Reads retained Perps events and updates activity, or permanently ends a subscription. Wallet and credential checks can close an invalid binding. These calls move no funds; replay is nondestructive even though its lifecycle effects require a destructive annotation.

| Tool                           | Use it for                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `deletePerpsEventSubscription` | Permanently end a native subscription without moving funds                                                    |
| `getPerpsEvents`               | Replay retained account events with an opaque cursor, explicit gaps and mandatory snapshot and health records |

## Rename a destination

Changes only a destination's label using its current version. It does not change the receiver URL, kind or credential and sends no request.

| Tool                       | Use it for                                                        |
| -------------------------- | ----------------------------------------------------------------- |
| `updateWebhookDestination` | Change a destination label using the version returned by the list |

## Register a webhook destination

Registers a webhook or routine destination shared by Perps and Predictions. Only webhooks can return a generated signing secret once. Routines require their own credentials. It changes only the destination Gina stores for your account and moves no funds. It is marked destructive so your client asks you first, and a secret it passes or returns appears in your client's transcript.

| Tool                       | Use it for                                                                                            |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| `createWebhookDestination` | Register a shared webhook or routine destination; only webhooks can return a generated signing secret |

## Change a webhook destination

Replaces a destination's signing secret or routine credential, disables it, or deletes a disabled, unattached destination. It moves no funds and is marked destructive so your client asks you first. Disabling and deletion cannot be undone. Check both products for attachments before disabling, then list the destination again to get its current version before deletion.

| Tool                             | Use it for                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------------- |
| `deleteWebhookDestination`       | Delete a disabled, unattached destination using the version returned after disabling           |
| `rotateWebhookDestinationSecret` | Replace a webhook signing secret or routine credential using the destination's rotation policy |
| `disableWebhookDestination`      | Disable a shared destination and pause subscriptions that use it                               |

## Test a webhook destination

Sends one optional test event to a registered destination and records the result. It can start a real automation or routine session and use the receiver's quota or paid usage, so it is not a read.

| Tool                   | Use it for                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------- |
| `sendWebhookTestEvent` | Send an optional receiver test; it can start a real automation or paid routine session |

## Sandbox

Runs commands in a sandbox that can call every host tool the venue allows, including the execute class, so it carries the strictest class of the tools it can reach.

| Tool   | Use it for                                                    |
| ------ | ------------------------------------------------------------- |
| `bash` | Scripts, files, SQL over captured data and composed workflows |

## Host tools that are not native

These host tools are not native tools. Sandbox-only tools run inside `bash` with `host-tools`.

| Tool                     | Why                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| `createHyperliquidTable` | Writes the caller's sandbox scratch table, so it only makes sense inside bash.           |
| `executeSqlQuery`        | Queries sandbox scratch tables, so it only makes sense inside bash.                      |
| `captureAnalysisDataset` | Captures a dataset for sandbox SQL and render tools, so it only makes sense inside bash. |

## Typed next steps

These tools return a typed `next` list beside their result. Each entry names a tool and arguments your client can offer as a button. Your client still shows the call and waits for your approval before it runs.

| Tool                          | Suggests                | When                                                                                                                                         |
| ----------------------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `fetchHyperliquidCandles`     | `perps.renderChart`     | Your client renders MCP Apps and the candles were captured. It suggests a candlestick chart of the captured rows.                            |
| `previewHyperliquidOrderCost` | `placeHyperliquidOrder` | The preview can fill. It suggests a limit order at the recommended price, and you can edit the size, price, order type and reduce-only flag. |

## Native only, blocked in bash

`updateHyperliquidIsolatedMargin`, `fundHIP3Dex`, `returnHIP3DexFunds` are native tools only. Inside `bash`, both `host-tools` and `ts-exec` refuse the call with `HOST_TOOL_LIVE_CONFIRMATION_REQUIRED`, so your MCP client can show the call and ask you first.

## Check that it works

1. Open your client's tool list for `https://askgina.ai/ai/perps/mcp`.
2. Confirm `bash` and the tools above appear, and that every tool in the Execute class is marked destructive.
3. Ask “Show my Hyperliquid positions.” and check that the assistant calls `getHyperliquidPositions`. Do not approve an Execute call you did not ask for.
