Gina's Perps MCP server lets you analyze markets, inspect account state, manage positions, and trade Hyperliquid perpetual futures from your AI coding assistant or MCP client.
For Ask Gina's broader user-facing capabilities, including wallets, market research, Recipes, Memory, networks, fees, and safety boundaries, see the [Product Guide](/product-guide).

## Server URL

```
https://askgina.ai/ai/perps/mcp
```

Perps MCP is available by default to authenticated Gina users. There is no separate perps MCP feature flag to enable.

## Quick Success Check

<Steps>
  <Step title="Add the server">
    Add `https://askgina.ai/ai/perps/mcp` to your MCP client and restart it.
  </Step>
  <Step title="Sign in">
    Your client triggers OAuth. Sign in to Gina in the browser and approve access.
  </Step>
  <Step title="Verify">
    Ask your AI assistant to use the `bash` tool:

    ```json
    { "command": "echo ok" }
    ```

    You should see `ok` in the output.

  </Step>
</Steps>

## Safety

<Warning>
  Perpetual futures use leverage and can liquidate quickly. Start with read-only commands such as
  prices, positions, and schemas before placing orders or moving funds.
</Warning>
