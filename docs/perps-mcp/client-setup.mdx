This is **write access (Degen mode)**. It requests `tools:execute` and can perform perps actions. For research only, use [Gina Read](/mcp-access/gina-read).

To install the Perps connection as a plugin instead, use `ask-gina-perps`. See [install for your host](/agents/plugins-and-skills#install-for-your-host).

## Claude Code

```sh
claude mcp add --transport http perps https://askgina.ai/ai/perps/mcp
```

Open `/mcp` in Claude Code and complete OAuth. See [Claude setup](/connect/claude) for the host's authentication flow.

## Codex

```sh
codex mcp add perps --url https://askgina.ai/ai/perps/mcp
codex mcp login perps
```

Alternatively, merge this into your Codex configuration, then run the login command:

```toml
[mcp_servers.perps]
url = "https://askgina.ai/ai/perps/mcp"
```

## Cursor

Merge the entry into `.cursor/mcp.json` or `~/.cursor/mcp.json`, preserving other servers:

```json
{
  "mcpServers": {
    "perps": {
      "url": "https://askgina.ai/ai/perps/mcp"
    }
  }
}
```

Connect and complete Gina OAuth from Cursor's MCP settings.

## Other clients and manual tokens

Use a [Streamable HTTP client](/connect/other-clients) with this venue URL. Check the host's support for execution tools before connecting. For Bearer-token clients, follow [authentication](/agents/authentication) and deliberately choose **Full access — view and execute**; keep only the required venue entry.

The credential must be valid for this venue and carry `tools:execute`. A read-only token or an old Gina execute grant is not a substitute. Complete a fresh connection if the grant is rejected.

Next: run the [read-only connection checks](/perps-mcp/quick-start) before attempting execution.

For account notifications without placing an order, follow [Account events](/perps-mcp/features#account-events). They use this same authenticated connector and its linked wallet, but need no trading delegation. A pull subscription needs no receiver or signing secret.

## Check that it works

Restart the client and complete Gina OAuth. In Claude Code, `/mcp` should list `perps` as connected, and `bash` should appear in the tool list. Call `bash` with:

```json
{ "command": "capabilities --json" }
```

Expected: one payload with `commands` and `hostTools`. The call only reads data. If `bash` is missing, remove the server, add it again and reconnect.
