Complete reference of Perps MCP capabilities. You can prompt naturally, or ask your client to call the native tool shown.

<Info>
  Call the [native Perps tools](/perps-mcp/tools) directly for reads, previews and orders. Use
  `bash` only for scripts, sandbox tables and SQL.
</Info>

## Account health

`getHyperliquidAccountHealth` requires an authenticated account. It defaults to canonical Hyperliquid. Pass `providerContext` with `{"providerId":"hip3:xyz"}` for an enabled HIP-3 venue.

Set `includeExitEstimates=true` for indicative exit estimates on a capped number of positions. They are not fill guarantees. The tool does not assign a health score or calculate historical performance.

## Market radar

`fetchHyperliquidMarketRadar` accepts an optional `limit` (its input schema gives the range) and an optional `dex`, such as `{"dex":"xyz"}`. Omit `dex` for canonical Hyperliquid.

Eligible markets rank by descending 24-hour traded volume, then open interest, then absolute 24-hour price change, with coin name breaking ties. This measures activity and exposure, not liquidity, depth, or executable size.

Rank, volume, open-interest, and mark-price deltas compare with a shared sample for that venue, not the caller's previous request. Samples rotate on a fixed minimum interval and expire after a retention window. Rows without a prior entry are marked `firstSeen`.

Radar returns the complete JSON response inline or in an artifact. It does not automatically extract the rows into SQL tables.

## Finding the right tool

Your client's tool list shows every native tool with its input schema, and [Native tools](/perps-mcp/tools) groups them by what they do. For a `bash` script, list the host tools the sandbox can call:

```json
{ "command": "host-tools --brief" }
```

## HIP-3 Provider Context

For HIP-3 tools, prefer provider context over legacy venue-only inputs:

```json
{
  "providerContext": {
    "providerId": "hip3:xyz"
  }
}
```

This keeps pricing, orders, margin, funding, and SQL analysis scoped to the selected HIP-3 provider.

## Check that it works

Call the native `getHyperliquidPrice` tool with:

```json
{ "coin": "BTC" }
```

Expected: JSON with the live BTC perpetual price. Or ask "BTC perps price" and check that the assistant calls `getHyperliquidPrice` instead of answering from memory.
