Perps MCP is Gina's dedicated MCP server for Hyperliquid perpetual futures. It exposes native tools for market data, account state, order costs, orders, leverage, deposits and withdrawals, and a sandboxed `bash` tool that can discover and call allowlisted perps host tools for HIP-3 DEX workflows, funding, and SQL analysis. [Native tools](/perps-mcp/tools) lists every native tool by annotation class.

## How It Works

Your MCP client connects to:

```
https://askgina.ai/ai/perps/mcp
```

After OAuth sign-in, the client receives the native tools, the `bash` tool and render-only tools such as `perps.renderChart`. Call a native tool directly for a one-off read or order. Inside the `bash` sandbox, use commands such as `capabilities`, `host-tools`, `sql`, and `ts-exec` to inspect the tool surface and run perps workflows.

## Default Access

Perps MCP is default enabled for authenticated Gina users. Runtime access is controlled by MCP authentication, not by a perps-specific feature flag.

## Check that it works

After you connect, call `bash` with:

```json
{ "command": "echo ok" }
```

Expected: `ok`. Then call `bash` with:

```json
{ "command": "host-tools getHyperliquidPrice '{\"asset\":\"BTC\"}'" }
```

Expected: JSON with the current BTC perpetual futures price under `data.payload`. Both calls only read data.
